3. Technical & Security Architecture

Zero Google Drive Links in Source Code: Public HTML contains no proprietary Drive links. Unauthenticated visitors see pitch overlay cards and access flows.

Dynamic Client-Side Authorization: The client script /js/content-gate.js verifies Firebase Auth and user role. Replay videos and slide decks populate dynamically into the DOM only after verifying active member status.

Speed to Lead: Every lead submission on the site logs into Firestore accessRequests. The Admin Command Base provides instant 1-click text (sms:) and email (mailto:) triggers to follow up within 30 seconds.

Cache Invalidation: Configured in firebase.json with strict revalidation headers so all browser and CDN caches stay fresh upon deployment.

4. External AI Engines

MoneyPrinterTurbo: Cloned locally at D:\Orca Command Base\Projects\MoneyPrinterTurbo for automated vertical video production (30-day topic list in Library).

VoiceStudio: Downloaded installer at D:\Downloads\VoiceStudio-Setup.exe for zero-cost local voice cloning and Spanish property video dubbing (SOP in Library).

5. Domain Setup for Tomorrow

To point realwolfpack.com to this deployment tomorrow:

  1. Open Firebase Console -> Hosting -> Sites -> real-wolf-pack -> Add custom domain.
  2. Enter realwolfpack.com and copy the 2 A-record IP addresses provided.
  3. Log into MojoHost DNS and update the A-records for realwolfpack.com.
  4. Google automatically provisions and installs the SSL certificate.
